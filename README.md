# AI, Economic Perceptions and Consumer Sentiment Ahead of the 2026 Midterms — reproducible package

Course: AI Applications in Finance — final project. Data cutoff: **2026-10-14** (midterm elections 2026-11-03).

This folder contains the full analytical package: data provenance, collectors, the coding scheme and LLM
prompts, the human-labeling guide and workbook, the models, the monitoring dashboard, the report and the
slide deck. Everything in `data/processed/`, `figures/`, `dashboard/` is regenerated by `run_all.sh`.

## Pipeline

```
collect_fred_alfred.py   FRED controls + ALFRED real-time vintages      -> data/raw/fred, data/raw/alfred
collect_michigan.py      Michigan Surveys of Consumers tables (xls)      -> data/raw/michigan
collect_gkg.py           GDELT GKG 15-minute slices (headlines)          -> data/raw/gkg/items_YYYY-MM.jsonl
collect_bluesky.py       Bluesky posts (public search API)               -> data/raw/bluesky/posts.jsonl
collect_gdelt_timelines.py  GDELT DOC API daily tone/volume timelines    -> data/raw/gdelt_timelines
build_macro_panel.py     monthly macro + survey panel, real-time panel   -> data/processed/macro_monthly.csv, realtime_panel.csv
econ_baseline.py         economic-only model, gap, prediction intervals  -> econ_baseline_*.csv/md, figures/fig1-3
prepare_corpus.py        clean/de-duplicate/classify corpora             -> news_items.parquet, social_items.parquet, corpus_summary.md
make_llm_batches.py      stratified LLM sample (seed 20261014)           -> data/processed/llm/in/batch_####.json, manifest.csv
classify_llm.py          API runner for the frozen prompt (needs key)    -> data/processed/llm/out/
merge_llm_outputs.py     schema validation + merge                       -> labels_llm.parquet, llm/validation_report.md
classify_baselines.py    GDELT tone, VADER, FinBERT, Twitter-RoBERTa, TF-IDF+LR -> baseline_scores.parquet, baseline_report.md
build_media_indices.py   monthly media measures + factual calibration    -> media_monthly.csv (+codebook), claims_checked.csv
models.py                M1/M2/M3, OOS tests, asymmetry, lead-lag, partisan -> models_summary.md, model_forecasts.csv, figures/fig4-8
perturbation_test.py     name-swap / source-label robustness             -> perturbation_report.md
make_labeling_sample.py  320-item human labeling workbook                -> labeling/human_label_sample.xlsx
eval_labels.py           agreement, adjudication list, AI performance    -> labeling/ai_performance.md
build_dashboard.py       monitoring dashboard                            -> dashboard/index.html
md_to_docx.py, md_to_pdf.py, build_slides.py   report (Word, PDF) and slides builders
```

Environment: Python 3.12 virtual environment in `.venv` (created with `uv venv --python 3.12`; packages in
`requirements.txt`). Transformers run on Apple MPS if available.

## Measurement validity and limits (short version; full discussion in the report)

* Media measures are **content supply**. Engagement counts (Bluesky likes/reposts) are imperfect attention
  measures. The only exposure/recall measure is Michigan's "news heard" question (tables 23–24).
* Text can establish framing and selective coverage; it cannot establish a reader's cognitive bias.
* The LLM labels were produced with the frozen prompt by `claude-haiku-5-5` through Claude Code sub-agents
  (`prompts/subagent_runner.md`); `src/classify_llm.py` reproduces them through the API.
* Human labels: the 320-item workbook is prepared; agreement and AI-vs-human performance are computed by
  `src/eval_labels.py` once two annotators have filled it (see report, section on validation status).

## How to update after the project cutoff

1. Append the new Michigan reading to `data/raw/michigan/manual_additions.csv` (or re-run `collect_michigan.py`).
2. Run the collectors (they resume), then `bash run_all.sh`. New months are sampled into new LLM batches;
   label them with `classify_llm.py` (API) or the sub-agent runner, then re-run from `merge_llm_outputs.py`.
3. Open `dashboard/index.html`.
